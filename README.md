# SENJA MERPATI — Island Mail Run

A complete, original flight game for the make.fun bounty
[Make the best flight game](https://make.fun/bounty/best-flight-game-20261126-0057):
fly a mail plane between Indonesian islands at golden hour — 5 missions,
12 golden rings, 3 islands, 2 runways, 1 carrier deck, 3 planes, 4 weather
events and 9 upgrades. Three.js chase view, full HUD (ALT / SPD / HDG),
fuel and damage that turn every sortie into decisions.

Play it: serve `game/` with any static server (`node serve.ts`, then open
http://localhost:8080) and fly with keyboard: ↑↓ pitch, ←→ bank, W/S throttle,
Space airbrake, P pause, M mute.
